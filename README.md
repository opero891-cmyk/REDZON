# REDZON - 64-bit Android Game Performance Optimizer

تطبيق متقدم لتحسين أداء الألعاب على أجهزة أندرويد 64-بت مع دعم كامل لصلاحيات الروت.

## نظرة عامة

REDZON هو تطبيق احترافي مخصص لـ:
- **تثبيت معدل الإطارات (FPS)** بشكل مطلق (30 / 60 / 90 / 120 FPS)
- **مراقبة النظام المباشرة** لـ CPU, GPU, RAM, ودرجة حرارة البطارية
- **تحسينات الأداء المتقدمة** لـ CPU, GPU, RAM, والتخزين
- **أوضاع أداء ذكية** (متوازن، أقصى أداء)
- **واجهة مستخدم احترافية** بتصميم Cyberpunk داكن

## المميزات الرئيسية

### 1. مراقبة النظام المباشرة
- **CPU Usage**: قراءة فعالة لاستخدام المعالج من `/proc/stat`
- **GPU Frequency & Usage**: مراقبة تردد وأداء كرت الشاشة
- **RAM Usage**: معلومات حية عن استخدام الذاكرة
- **Battery Temperature**: قراءة درجة حرارة البطارية
- تحديث البيانات كل ثانية بدون تأثير على الأداء

### 2. تثبيت معدل الإطارات FPS
يوفر الطريقة التالية:
- **أزرار سريعة**: 30 / 60 / 90 / 120 FPS
- **أوامر ROOT**: 
  - `settings put system peak_refresh_rate [FPS]`
  - `settings put system min_refresh_rate [FPS]`

### 3. تحسينات الأداء المتقدمة

#### تحسين CPU
```kotlin
echo performance > /sys/devices/system/cpu/cpu*/cpufreq/scaling_governor
```
- تفعيل جميع أنوية المعالج
- القضاء على التقليل التلقائي للتردد

#### تحسين GPU
```kotlin
echo [max_freq] > /sys/class/kgsl/kgsl-3d0/devfreq/max_freq
echo [max_freq] > /sys/class/kgsl/kgsl-3d0/devfreq/min_freq
```
- قفل GPU على أعلى تردد
- تحسين أداء الرسومات بشكل مباشر

#### تحسين RAM
```kotlin
sysctl -w vm.drop_caches=3
```
- تفريغ الذاكرة المؤقتة
- تحرير موارد إضافية للعبة

#### تحسين I/O
```kotlin
echo noop > /sys/block/*/queue/scheduler
```
- تسريع قراءة البيانات من التخزين
- تقليل زمن التحميل

#### إدارة الحرارة
- تعطيل كبح الحرارة الثرمالي للحصول على أداء أقصى
- تفعيل كبح الحرارة للحماية من الحرارة الزائدة

### 4. أوضاع الأداء

#### الوضع المتوازن (Balanced)
- قفل FPS على 90
- تحسين CPU بوضع الأداء
- تحسين RAM

#### الأداء الأقصى (Extreme)
- قفل FPS على 120
- قفل CPU على أقصى أداء
- قفل GPU على أقصى تردد
- تحسين RAM
- تحسين I/O
- تعطيل كبح الحرارة

#### إعادة التعيين (Reset)
- استعادة جميع الإعدادات الافتراضية
- العودة للحالة الطبيعية

## بنية المشروع

### الملفات الرئيسية

1. **MainActivity.kt**
   - لوحة التحكم الرئيسية
   - عرض المقاييس المباشرة
   - أزرار التحكم بـ FPS
   - أوضاع الأداء المتقدمة

2. **SplashActivity.kt**
   - شاشة البداية
   - فحص صلاحيات الروت
   - واجهة ترحيبية احترافية
   - شريط تقدم متحرك

3. **RootCommand.kt**
   - تنفيذ أوامر الروت
   - دالات التحسين المختلفة
   - إدارة الأوامر البرمجية

4. **SystemMonitor.kt**
   - مراقبة موارد النظام
   - حساب استخدام CPU
   - قراءة معلومات GPU والحرارة

5. **MonitoringService.kt**
   - خدمة المراقبة الخلفية
   - مراقبة صحة النظام المستمرة

## المتطلبات

- **النظام**: Android 8.0+ (API 26+)
- **المعمارية**: 64-bit (ARM64-v8a)
- **صلاحيات الروت**: مطلوبة للوظائف الكاملة
  - Magisk
  - KernelSU
  - APatch

## كيفية الاستخدام

1. **تشغيل التطبيق**
   - سيفحص التطبيق صلاحيات الروت تلقائياً
   - سيعرض حالة الاتصال

2. **قفل FPS**
   - انقر على أحد أزرار FPS (30 / 60 / 90 / 120)
   - سيتم تثبيت معدل التحديث فوراً

3. **تطبيق أوضاع الأداء**
   - اختر "الوضع المتوازن" أو "أداء أقصى"
   - التطبيق سيطبق جميع التحسينات تلقائياً

4. **الإعدادات المتقدمة**
   - استخدم الإعدادات المتقدمة للتحكم الدقيق
   - مراقبة النتائج من لوحة المراقبة

## ملاحظات تقنية

### الأداء
- استخدام `withContext(Dispatchers.IO)` لتنفيذ أوامر الروت بدون تجميد الواجهة
- قراءة المقاييس مرة واحدة في الثانية
- استخدام `LazyColumn` لتقليل استهلاك الذاكرة

### الأمان
- التطبيق يتحقق من صلاحيات الروت قبل محاولة أي عملية
- جميع الأوامر تُنفذ عبر `su` بشكل آمن
- عدم حفظ أي بيانات حساسة

### التوافق
- يعمل على Android 8.0+ (API 26)
- مدعوم على جميع معالجات ARM64-v8a
- واجهة RTL كاملة لدعم اللغات العربية
