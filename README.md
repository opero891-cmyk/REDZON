# REDZON - 64-bit Game Performance Optimizer & System Control (React + TypeScript)

تطبيق متقدم ومحاكي احترافي لتحسين أداء الألعاب ومراقبة النظام لأجهزة أندرويد 64-بت (ARM64-v8a) مع دعم صلاحيات الروت وأوامر Kernel Sysfs المباشرة.

---

## 🚀 المميزات الرئيسية

### 1. مراقبة النظام المباشرة (Live System Monitor)
- **استخدام المعالج CPU**: قراءة ومحاكاة دقيقة لبيانات `/proc/stat` مع تمثيل بياني حي.
- **استخدام وتردد معالج الرسوميات GPU**: مراقبة حية لترددات `kgsl-3d0` و `devfreq` حتى 825 MHz.
- **استخدام الذاكرة العشوائية RAM**: عرض الذاكرة المستخدمة والمتاحة بالميجابايت مع تأثيرات التفريغ الفوري.
- **درجة حرارة البطارية**: قراءة مباشرة مع تنبيهات عند تجاوز 40°C وتغير لون المؤشر.
- **معدل التحديث الفعلي Active FPS**: مؤشر نشط لمعدل الإطارات اللحظي.

### 2. تثبيت وقفل معدل الإطارات (FPS Lock Controller)
- أزرار سريعة لقفل التردد على: **30 FPS / 60 FPS / 90 FPS / 120 FPS**.
- تنفيذ أوامر الروت المباشرة:
  ```bash
  settings put system peak_refresh_rate [FPS]
  settings put system min_refresh_rate [FPS]
  ```
- إمكانية إلغاء القفل والعودة للوضع الديناميكي.

### 3. أوضاع الأداء الذكية (Smart Performance Profiles)
- **الوضع المتوازن (Balanced - 90 FPS)**:
  - ضبط حاكم المعالج على `powersave`
  - تثبيت التحديث على 90 FPS
  - تفريغ ذاكرة التخزين المؤقت للـ RAM
- **الأداء الأقصى (Extreme - 120 FPS + Unlocked)**:
  - تفعيل وضع `performance` لجميع الأنوية الثمانية
  - قفل تردد كرت الشاشة GPU على أقصى تردد (825 MHz)
  - قفل الإطارات على 120 FPS
  - تعطيل كبح الحرارة (Thermal Throttling)
  - تحسين جدولة وحدات التخزين `noop`
- **إعادة التعيين (Reset Defaults)**:
  - استعادة الإعدادات الافتراضية للكيرنل ونظام أندرويد.

### 4. الإعدادات والتحسينات المتقدمة (Kernel Sysfs & Tweaks)
- **تحسين CPU**: ضبط `scaling_governor` على `performance` لجميع الأنوية.
- **تحسين GPU**: كتابة التردد الأقصى في مسارات `sys/class/kgsl/kgsl-3d0/devfreq`.
- **تحسين RAM**: تنفيذ `sync` و `sysctl -w vm.drop_caches=3`.
- **إدارة كبح الحرارة (Thermal Throttling)**: تفعيل أو تعطيل `msm_thermal`.
- **تحسين I/O**: تبديل جدولة أقراص التخزين إلى `noop`.

### 5. موجه أوامر ROOT Shell Terminal
- عرض فوري لجميع أوامر `su -c` المنفذة مع النتائج وأكواد الإرجاع.
- دعم إدخال وتنفيذ أوامر Shell مخصصة.
- إمكانية نسخ الأوامر بنقرة واحدة.

### 6. شاشة البداية ومواصفات الجهاز (Splash Screen & Device Specs)
- شاشة بداية تفاعلية بمؤشر دائري متحرك ومحاكاة فحص صلاحيات الروت.
- نافذة مفصلة لمواصفات المعالج والـ SoC وحالة SELinux والكيرنل.
- دعم كامل للغتين العربية (افتراضي RTL) والإنجليزية (LTR).
